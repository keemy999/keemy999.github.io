Astrofy를 활용한 개인 포트폴리오 제작

이번 실습에서는 Astrofy 템플릿을 이용해 개인 포트폴리오 웹사이트를 제작했습니다. 기본으로 제공되는 페이지와 메뉴를 확인하고, 실제로 필요한 내용만 남겨 제 정보에 맞게 수정했습니다.

자기소개 및 프로필

홈 화면에 이름, 학교, 전공과 간단한 자기소개를 작성했습니다. 현재 공부하고 있는 웹 개발, 컴퓨터 시스템, 하드웨어 분야와 앞으로 배우고 싶은 기술들을 정리했습니다. 프로필 사진과 GitHub 주소도 추가하여 저에 대한 기본 정보를 확인할 수 있도록 했습니다.

프로젝트 정리

Projects 페이지에는 현재 기획하고 있는 소형 위치 추적 태그와 실용 웹 애플리케이션 프로젝트를 추가했습니다. 각 프로젝트의 목적과 간단한 설명을 작성하고, 관련 이미지도 함께 넣었습니다. 아직 개발을 진행 중인 프로젝트이므로 앞으로 구현 과정과 결과물을 추가할 예정입니다.

웹사이트 수정

기본 템플릿에 포함되어 있던 불필요한 메뉴와 예시 콘텐츠를 삭제하고, 메뉴와 페이지 내용을 한글로 수정했습니다. 기존 디자인은 최대한 유지하면서 자기소개, 기술 및 도구, 전공 학습, 관심 분야 등을 제 내용으로 채웠습니다.

웹사이트를 수정하면서 각 파일이 담당하는 역할을 확인할 수 있었고, 원하는 내용을 변경하기 위해서는 기존 코드의 구조를 파악하는 것이 중요하다는 점도 알게 되었습니다.

마무리

Astrofy 템플릿을 활용하여 개인 포트폴리오의 전체적인 구조를 구성할 수 있었습니다. 직접 페이지의 내용을 수정하고 이미지를 추가하면서 Astro 프로젝트의 구성 방식도 익힐 수 있었습니다.

앞으로 새로운 프로젝트를 진행하거나 전공 공부를 하면서 얻은 결과물을 이 포트폴리오에 꾸준히 추가할 계획입니다.
