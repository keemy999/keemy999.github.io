소형 위치 추적 태그

자주 챙기는 소지품을 분실하지 않고 금방 찾을 수 있도록 소형 위치 추적 장치를 만드는 프로젝트입니다. 일상에서 편하게 휴대할 수 있는 크기를 기준으로 실제 사용 환경을 고려한 하드웨어와 연결 시스템을 구상하고 있습니다.
문제 정의

소지품을 분실했을 때 위치를 확인하기 어렵고, 찾는 데 시간과 불편함이 발생하는 문제를 해결하고자 합니다.

담당 역할

프로젝트 기획, 장치 구성 검토, 하드웨어 설계 및 구현 방향 설정

사용 기술

임베디드 시스템, 하드웨어 설계, 무선 통신 관련 기술 (구체적인 기술 선정 및 검토 중)

진행 내용

소형화와 휴대성을 고려해 장치 구성, 위치 확인 방식, 통신 방식 및 전력 효율을 검토하고 있습니다.

진행 상태

현재 기획 및 설계 단계이며, 기능과 하드웨어 구성을 구체화하고 있습니다.

소스 코드 및 데모

구현 및 실제 장치 제작 후 GitHub 소스 코드와 시연 영상을 공개할 예정입니다.

실용 웹 애플리케이션

일상생활에서 발생하는 불편함이나 비효율적인 상황을 개선하기 위해 실질적인 기능을 제공하는 웹 애플리케이션을 기획하고 개발하는 프로젝트입니다. 아이디어 선정부터 서비스 구조 설계, 기능 구현까지 직접 해보는 것을 목표로 합니다.
문제 정의

일상에서 반복되는 불편함이나 비효율적인 과정을 웹 서비스로 개선할 수 있는 방법을 찾고자 합니다.

담당 역할

아이디어 선정, 서비스 기획, 화면 및 기능 설계, 웹 애플리케이션 개발

사용 기술

HTML, CSS, JavaScript (필요 기능에 따라 백엔드 및 데이터베이스 기술 추가 검토)

진행 내용

해결할 문제와 서비스 아이디어를 구체화하고, 사용자에게 필요한 기능과 화면 구성을 정리하고 있습니다.

진행 상태

현재 아이디어 및 기능 기획 단계이며, 구체적인 서비스와 구현 결과물을 준비하고 있습니다.

소스 코드 및 데모

개발 진행 후 GitHub 공개 및 실제 서비스 구현 후 웹 링크 또는 시연 영상을 공개할 예정입니다.
